# Seguranca

Nunca abra issue ou pull request contendo token, senha, URL de banco, chave privada, QR Code, sessao do WhatsApp ou dados pessoais de lead.

Se um segredo for exposto, remova-o do ambiente publico, revogue-o no provedor e substitua-o. Apagar apenas o arquivo do ultimo commit nao remove o segredo do historico.

O repositorio publico contem somente codigo e exemplos vazios. O acesso a producao e concedido individualmente e pode ser revogado sem trocar o acesso de outras pessoas.
