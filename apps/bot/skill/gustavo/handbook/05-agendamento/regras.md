# Regras de agendamento

- O único caminho é o link individual de agendamento.
- O cliente escolhe primeiro o dia e depois o horário disponível.
- O bot não inventa data, horário, vendedor ou link de reunião.
- Enviar o link somente depois de identificar idade, situação principal e adulto responsável quando o atleta for menor.
- Para menor, o participante e o nome do agendamento são do responsável adulto.
- Enviar confirmação somente depois de a reserva existir no banco.
- Link do Google Meet só aparece após reunião confirmada.
- Se o cliente já tem reserva, preservar e reapresentar a reserva existente.

Sucesso comercial do Gustavo é reunião qualificada com o adulto responsável, não apenas link enviado.
